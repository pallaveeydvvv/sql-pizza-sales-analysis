# SQL Pizza Sales Analysis 🍕

This project is based on analyzing pizza sales data using SQL to understand customer behavior, delivery trends, product performance, and revenue generation.

I built this project while learning SQL and database concepts to improve my analytical thinking, query writing, and understanding of relational databases.

---

# Project Goals

The main goal of this project was to:

* Practice SQL using a real-world style dataset
* Understand database relationships and schema design
* Perform exploratory data analysis using SQL
* Generate business insights from raw transactional data
* Improve problem-solving and query-building skills

---

# Dataset Information

The dataset contains information about:

* Customers
* Orders
* Pizza details
* Pizza categories
* Order quantities
* Delivery status

The data is organized into multiple related tables using primary and foreign key relationships.

---

# Database Schema

The project contains the following tables:

| Table         | Purpose                                 |
| ------------- | --------------------------------------- |
| customers     | Stores customer details                 |
| orders        | Stores order information                |
| order_details | Stores quantity of pizzas per order     |
| pizzas        | Stores pizza prices and sizes           |
| pizza_types   | Stores pizza categories and ingredients |

---

# Database Relationships

Some important relationships used in the project:

* One customer can place multiple orders
* One order can contain multiple pizzas
* One pizza type can exist in different sizes
* One pizza can appear in multiple order records

Primary keys and foreign keys were added to maintain relational integrity.

# Revenue Analysis

Revenue analysis was performed only on successful or delivered orders.

To simplify analysis, multiple SQL views were created.

### Views Created

## delivered_order

Contains only successful/delivered orders.

## pizza_delivery_detail

Contains delivered pizza records with pricing information.

## revenue_per_pizza

Contains revenue generated by each pizza.

# Business Insights

Some insights generated from the analysis:

* A small number of pizzas contribute heavily to total revenue.
* Successful deliveries are the major source of revenue generation.
* Certain customers place orders more frequently than others.
* Some pizzas are highly ordered but not necessarily the highest revenue generating.
* Failed and cancelled orders directly impact business revenue.
* Order volumes vary across different dates, indicating peak demand periods.
